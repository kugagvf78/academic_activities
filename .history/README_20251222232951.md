# Academic Competition Management System

## Overview

The **Academic Competition Management System** is a web-based application developed to support the management and organization of academic competitions at the Faculty of Information Technology.

The system aims to digitize and standardize core academic competition processes such as planning, organizing, registration, evaluation, and result management.  
It enhances transparency, operational efficiency, and interaction between students, lecturers, and academic administrators, contributing to the digital transformation of academic management.

This project is developed as part of an **academic graduation project / scientific research project**.

---

## Main Features

### For Students

-   Register for academic competitions (individual or team)
-   Submit competition entries by rounds
-   Register for cheering or supporting activities
-   Track competition status and results

### For Academic Affairs / Faculty

-   Create and manage academic competition plans
-   Approve and publish competition announcements
-   Manage competition rounds and submissions
-   Assign judges and supporting teams
-   Aggregate results and generate reports

### For Judges

-   Access competition submissions
-   Evaluate and score entries
-   Provide feedback and comments

## Technology Stack

-   **Backend:** PHP (Laravel Framework)
-   **Frontend:** Blade Template, HTML, CSS, JavaScript
-   **Asset Build Tool:** Vite (npm)
-   **Database:** PostgreSQL / MySQL
-   **Version Control:** Git, GitHub

---

## Requirements

-   PHP >= 8.0
-   Composer
-   Node.js & npm
-   PostgreSQL or MySQL

---

## Setup & Run Project

```bash
# Clone repository
git clone https://github.com/kugagvf78/academic_competition_system.git
cd academic_competition_system

# Install backend dependencies
composer install

# Install frontend dependencies
npm install
npm run dev

# Environment setup
cp .env.example .env
php artisan key:generate

# Configure database in .env
# DB_DATABASE=academic_competition
# DB_USERNAME=your_username
# DB_PASSWORD=your_password

# Run database migrations (if applicable)
php artisan migrate

# Start application
php artisan serve
```
